## Transcript / Meeting Note Files

**Format:** `YYYY-MM-DD_Participants_Topic.md`

| Element | Rule | Example |
|---|---|---|
| Date | ISO format, no slashes | `2026-07-20` |
| Participants | First names or initials, hyphen-separated | `Ed-Christine` or `Ed-Sage` |
| Topic | Short descriptor, hyphen-separated, no spaces | `AI-Workflow-Onboarding` |
| Extension | Always `.md` | `.md` |

**Examples:**
```
2026-07-20_Ed-Christine_AI-Workflow-Onboarding.md
2026-07-20_Ed-Sage_RMA-Podcast-Recording.md
2026-07-07_Ed-Christine-Victor_Camp-Audax-Planning.md
```

**Why:** Colons in filenames break Obsidian title rendering. The previous convention (`STE: Ed + Christine - July 20`) is incompatible.

## SOPs and Reference Docs

Use lowercase kebab-case, no dates unless versioned:
- `sop-openprojects-onboarding.md`
- `naming-conventions.md`
- `ste-data-location-rules.md`

---

## ⚠️ Characters to Avoid in Filenames

| Character | Reason to avoid |
|---|---|
| `:` colon | Breaks Obsidian title lines |
| `+` plus | Ambiguous in URLs |
| spaces | Shell/URL escaping issues |
| `&` ampersand | Shell special character |

**Use hyphens** (`-`) as word separators. Use underscores (`_`) to separate logical sections (date, participants, topic).
